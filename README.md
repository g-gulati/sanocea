# Sanocea Website

Premium React/Vite landing site for Sanocea.

## Local
```bash
npm install
npm run dev
```

## GitHub Pages
1. Create a repo under `g-gulati`.
2. Push this project to `main`.
3. GitHub → Settings → Pages → Build and deployment → **GitHub Actions**.
4. The included workflow deploys the site.
5. `public/CNAME` is already set to `sanocea.com`.

Do not change Namecheap DNS until the GitHub Pages deployment works on the GitHub-provided URL.
